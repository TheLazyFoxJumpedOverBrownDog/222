# Basic Website Template

This is a simple 2-page website template for your web design project.  
It includes:

- A **Home Page** with:
  - Header and navigation bar  
  - Hero banner with centered text  
  - “Collections” section with 3 hoverable images  
  - Footer with social media icons  

- A **Content Page** with:
  - Image and text side-by-side layout  
  - Repeated “Collections” section  
  - Same header and footer as the home page
